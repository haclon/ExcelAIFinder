## 软件概述

### 产品简介
ExcelAIFinder是一款基于人工智能技术的Excel内容智能查找工具，专为需要在大量Excel文件中快速定位特定信息的用户设计。软件结合了传统关键词搜索和AI语义理解技术，能够准确识别和定位相关内容，大幅提升工作效率。

### 核心特性
- **智能语义搜索**：基于SophNet AI技术，理解搜索意图而非仅匹配关键词
- **批量文件处理**：支持同时处理多个Excel文件，自动识别.xlsx和.xls格式
- **多模式分析**：提供精确匹配、语义理解、平衡模式三种搜索策略
- **详细结果展示**：显示匹配位置、工作表名称、具体内容和相关度评分
- **智能优化策略**：自动跳过高匹配度内容的AI分析，节约Token消耗
- **实时进度跟踪**：批量处理时显示详细进度信息

### 适用场景
- 财务报表数据查找
- 合同条款检索
- 项目文档筛选
- 客户信息定位
- 库存数据分析
- 任何需要在Excel文件中快速定位信息的场景

## 系统要求

### 硬件要求
- **处理器**：Intel Core i3或同等性能处理器
- **内存**：4GB RAM（推荐8GB或更高）
- **存储空间**：至少500MB可用磁盘空间
- **网络**：稳定的互联网连接（用于AI分析功能）

### 软件要求
- **操作系统**：Windows 10/11、macOS 10.14+、Ubuntu 18.04+
- **Node.js**：版本14.0.0或更高
- **浏览器**：Chrome 80+、Firefox 75+、Safari 13+、Edge 80+

### 网络要求
- 稳定的互联网连接
- 能够访问SophNet API服务
- 建议带宽：至少1Mbps上行速度

## 安装与配置

### 第一步：环境准备

#### 1.1 安装Node.js
访问 [Node.js官网](https://nodejs.org/) 下载并安装最新的LTS版本。

验证安装：
```bash
node --version
npm --version
```

#### 1.2 获取软件
从GitHub仓库克隆或下载软件：
```bash
git clone git@github.com:haclon/ExcelAIFinder.git
cd ExcelAIFinder
```

### 第二步：依赖安装

#### 2.1 安装前端依赖
```bash
npm install
```

#### 2.2 安装后端依赖
```bash
cd server
npm install
cd ..
```

### 第三步：配置设置

#### 3.1 环境配置
复制环境配置模板：
```bash
cp server/env.example server/.env
```

#### 3.2 编辑配置文件
打开 `server/.env` 文件，配置以下参数：

```env
# 服务器配置
PORT=3001
NODE_ENV=development

# SophNet AI API配置（必需）
SOPHNET_API_URL=https://www.sophnet.com/api/open-apis/v1/chat/completions
SOPHNET_API_KEY=your_sophnet_api_key_here
SOPHNET_MODEL=DeepSeek-R1
SOPHNET_MAX_TOKENS=32768

# 文件上传配置
MAX_FILE_SIZE=50MB
UPLOAD_PATH=./uploads

# 日志配置
LOG_LEVEL=info
LOG_FILE=./logs/app.log
```

**重要提示**：必须配置有效的SophNet API密钥才能使用AI语义分析功能。

### 第四步：启动软件

#### 4.1 完整启动（推荐）
```bash
npm run dev
```
此命令将同时启动前端和后端服务。

#### 4.2 分别启动
如需分别启动服务：

**启动后端**：
```bash
npm run server:dev
```

**启动前端**（新终端）：
```bash
npm run serve
```

### 第五步：访问软件
- **前端界面**：http://localhost:8080
- **后端API**：http://localhost:3001

## 功能使用指南

### 基本搜索流程

#### 步骤1：选择Excel文件

![文件选择截图](docs/images/file-selection.png)

1. 点击"选择本地文件夹"按钮
2. 在弹出的文件夹选择对话框中，选择包含Excel文件的文件夹
3. 软件将自动识别文件夹中的.xlsx和.xls文件
4. 在界面上确认已选择的文件数量

**注意事项**：
- 支持嵌套文件夹，软件会递归搜索所有子文件夹
- 单次建议处理不超过20个文件以确保性能
- 单个文件大小限制为50MB

#### 步骤2：输入搜索内容

![搜索输入截图](docs/images/search-input.png)

1. 在搜索输入框中输入要查找的内容
2. 支持中英文混合搜索
3. 可以输入关键词、短语或描述性文本
4. 按Enter键或点击"分析"按钮开始搜索

**搜索技巧**：
- 使用具体的关键词能提高匹配精度
- 描述性语句有助于AI理解搜索意图
- 避免过于宽泛的搜索词

#### 步骤3：配置搜索选项（可选）

![高级选项截图](docs/images/advanced-options.png)

点击"高级选项"展开详细设置：

**理解模式**：
- **语义理解**：使用AI分析内容语义，理解搜索意图
- **精确匹配**：仅查找包含确切关键词的内容
- **平衡模式**：结合精确匹配和语义分析

**相关度阈值**：
- 设置0-100的分数范围
- 只显示高于阈值的结果
- 建议设置为50以过滤低相关度结果

**分析深度**：
- **浅层分析**：快速分析，适合大批量文件
- **深度分析**：详细分析，准确度更高但速度较慢

#### 步骤4：开始分析

![分析进度截图](docs/images/analysis-progress.png)

1. 确认所有设置后，点击"分析"按钮
2. 软件开始批量处理选中的Excel文件
3. 实时显示处理进度和日志信息
4. 可以随时查看已完成的分析结果

**进度信息包括**：
- 当前处理的批次和总批次数
- 处理进度百分比
- 每个文件的处理状态
- 发现的匹配数量统计

#### 步骤5：查看结果

![结果展示截图](docs/images/results-display.png)

分析完成后，结果按相关度从高到低排序显示：

**结果概览**：
- 文件名和相关度评分
- 匹配内容数量
- 快速操作按钮

**详细内容**：
- 点击"查看详情"展开具体匹配内容
- 显示工作表名称和行号
- 高亮显示匹配的关键词
- 提供完整内容查看功能

**批量操作**：
- 展开/收起所有结果
- 按不同条件排序

### 结果解读

#### 相关度评分说明
- **81-100分**：极高相关，内容完全匹配搜索意图
- **61-80分**：高度相关，内容与搜索高度匹配
- **41-60分**：中度相关，内容部分匹配搜索意图
- **21-40分**：轻微相关，内容可能包含相关信息
- **0-20分**：基本无关，建议忽略

#### 匹配内容格式
每个匹配项显示以下信息：
- **工作表名称**：匹配内容所在的工作表
- **行号**：具体的行位置
- **匹配内容**：包含搜索词的完整行内容
- **单元格详情**：显示该行各列的具体数值

## 高级功能

### API配置管理

![API配置截图](docs/images/api-config.png)

#### 配置SophNet API
1. 点击界面右上角的"API配置"按钮
2. 在弹出的对话框中输入以下信息：
   - **API地址**：SophNet API的完整URL
   - **API密钥**：您的SophNet API密钥
   - **模型选择**：选择要使用的AI模型
   - **最大Token数**：设置单次请求的Token限制

3. 点击"测试连接"验证配置是否正确
4. 保存配置并关闭对话框

#### 支持的AI模型
- DeepSeek-R1（推荐）
- DeepSeek-v3
- Qwen3-235B-A22B
- Qwen2.5-72B-Instruct
- Qwen2.5-32B-Instruct
- QwQ-32B
- Qwen2.5-7B-Instruct

### 批量处理优化

#### 智能批处理策略
软件采用智能批处理机制来处理大量文件：

1. **自动分批**：当文件数量超过设定阈值时，自动分批处理
2. **进度跟踪**：实时显示每个批次的处理进度
3. **错误恢复**：单个文件处理失败不影响其他文件
4. **资源优化**：根据系统性能自动调整处理速度

#### 批处理参数配置
- **批次大小**：每批处理的文件数量（默认10个）
- **超时设置**：单个文件的最大处理时间
- **重试机制**：失败文件的重试次数
- **并发控制**：同时处理的文件数量限制

### 智能优化功能

#### Token使用优化
为了节约API调用成本，软件实现了多种优化策略：

1. **自动跳过策略**：
   - 当文件中直接匹配超过5处时，跳过AI分析
   - 基于匹配数量计算相关度分数
   - 显著减少API调用次数

2. **内容截取优化**：
   - 只分析包含关键词的文本片段
   - 限制单次分析的文本长度（最多1000字符）
   - 智能选择最相关的内容片段

3. **缓存机制**：
   - 缓存相同内容的分析结果
   - 避免重复的API调用
   - 提高处理速度

#### 性能监控
软件提供详细的性能监控信息：
- API调用次数统计
- Token使用量跟踪
- 处理时间分析
- 错误率监控

## 故障排除

### 常见启动问题

#### 问题1：端口占用错误
**错误信息**：`Error: listen EADDRINUSE: address already in use :::3001`

**解决方案**：
```bash
# 方法1：杀死占用进程
netstat -ano | findstr :3001
taskkill /PID <进程ID> /F

# 方法2：修改端口
# 编辑 server/.env 文件，将 PORT=3001 改为其他端口
```

#### 问题2：依赖安装失败
**错误信息**：`npm install` 过程中出现错误

**解决方案**：
```bash
# 清除缓存重新安装
npm cache clean --force
rm -rf node_modules package-lock.json
npm install
```

#### 问题3：Node.js版本不兼容
**错误信息**：版本相关的错误提示

**解决方案**：
1. 检查Node.js版本：`node --version`
2. 确保版本 >= 14.0.0
3. 如需升级，访问 [Node.js官网](https://nodejs.org/) 下载最新版本

### API连接问题

#### 问题1：API密钥无效
**错误信息**：`认证失败 (401): 请检查API密钥是否正确`

**解决方案**：
1. 确认API密钥格式正确
2. 检查密钥是否已过期
3. 联系SophNet获取有效密钥

#### 问题2：网络连接超时
**错误信息**：`API请求超时，请稍后重试`

**解决方案**：
1. 检查网络连接状态
2. 确认能够访问SophNet API服务
3. 尝试使用VPN或更换网络环境

#### 问题3：API配额不足
**错误信息**：相关的配额限制提示

**解决方案**：
1. 检查API账户余额
2. 升级API服务套餐
3. 优化搜索策略减少API调用

### 文件处理问题

#### 问题1：Excel文件无法读取
**错误信息**：`无法读取Excel文件`

**解决方案**：
1. 确认文件格式为.xlsx或.xls
2. 检查文件是否损坏
3. 确认文件未被其他程序占用
4. 检查文件大小是否超过50MB限制

#### 问题2：中文文件名乱码
**错误信息**：文件名显示为乱码

**解决方案**：
1. 确保系统支持UTF-8编码
2. 重命名文件使用英文名称
3. 检查浏览器编码设置

#### 问题3：内存不足
**错误信息**：处理大文件时出现内存错误

**解决方案**：
1. 减少同时处理的文件数量
2. 关闭其他占用内存的程序
3. 增加系统内存
4. 分批处理大型文件

## 常见问题

### Q1：软件支持哪些Excel文件格式？
**A**：支持Microsoft Excel 2007及以上版本的.xlsx格式，以及Excel 97-2003的.xls格式。单个文件大小限制为50MB。

### Q2：AI分析功能是否必需？
**A**：不是必需的。软件提供三种搜索模式：
- 精确匹配模式：不使用AI，仅进行关键词匹配
- 语义理解模式：使用AI进行语义分析
- 平衡模式：结合两种方式

### Q3：如何获取SophNet API密钥？
**A**：需要访问SophNet官网注册账户并申请API密钥。具体步骤请参考SophNet的官方文档。

### Q4：软件是否会上传我的Excel文件到云端？
**A**：文件仅上传到本地服务器进行处理，不会传输到第三方云服务。AI分析时只发送必要的文本片段，不包含完整文件内容。

### Q5：可以同时处理多少个Excel文件？
**A**：理论上没有数量限制，但建议单次处理不超过20个文件以确保性能。软件支持批量处理，会自动分批处理大量文件。

### Q6：搜索结果的相关度分数如何计算？
**A**：相关度分数由AI模型基于内容语义相关性计算得出，范围为0-100分。分数越高表示内容与搜索意图越匹配。

### Q7：软件是否支持离线使用？
**A**：基本搜索功能（精确匹配模式）可以离线使用，但AI语义分析功能需要网络连接。

### Q8：如何提高搜索准确度？
**A**：建议：
- 使用具体明确的搜索词
- 根据内容类型选择合适的理解模式
- 设置合理的相关度阈值
- 使用描述性语句帮助AI理解搜索意图

### Q9：软件对系统性能有什么要求？
**A**：建议配置：
- 4GB以上内存
- 稳定的网络连接
- 现代浏览器
- 处理大量文件时建议8GB以上内存

### Q10：如何备份和恢复配置？
**A**：配置信息保存在`server/.env`文件中，可以备份此文件。恢复时将备份文件复制到相应位置即可。
