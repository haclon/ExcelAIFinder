当前"文档鉴别材料"文件夹中的图片文件都是**占位文件**，需要您手动将实际的图片文件从原位置复制过来。

## 🔧 手动复制步骤

### 方法1：使用文件资源管理器（推荐）

1. **打开源文件夹**
   - 导航到项目根目录
   - 进入 `docs/images/` 文件夹
   - 您应该看到7个PNG文件，大小从44KB到156KB不等

2. **选择所有图片文件**
   - 按 `Ctrl+A` 选择所有文件
   - 或者手动选择所有PNG文件

3. **复制文件**
   - 按 `Ctrl+C` 复制文件

4. **打开目标文件夹**
   - 导航到 `文档鉴别材料/docs/images/` 文件夹
   - 您会看到同名的占位文件（每个只有1字节）

5. **粘贴并替换**
   - 按 `Ctrl+V` 粘贴文件
   - 当系统询问是否替换现有文件时，选择"是"或"替换"

### 方法2：使用命令行

#### Windows (PowerShell)
```powershell
# 在项目根目录执行
Copy-Item "docs\images\*.png" "文档鉴别材料\docs\images\" -Force
```

#### Windows (命令提示符)
```cmd
# 在项目根目录执行
copy "docs\images\*.png" "文档鉴别材料\docs\images\"
```

#### macOS/Linux
```bash
# 在项目根目录执行
cp docs/images/*.png 文档鉴别材料/docs/images/
```

## 🔍 故障排除

### 问题1：复制后文件大小仍然是1字节
**原因**：复制操作失败或路径错误  
**解决**：
1. 确认源文件路径正确
2. 确认目标文件夹存在
3. 重新执行复制操作

### 问题2：图片在Markdown中不显示
**原因**：路径问题或文件损坏  
**解决**：
1. 检查图片文件是否完整复制
2. 确认文件名大小写正确
3. 使用图片查看器打开文件验证

### 问题3：权限错误
**原因**：文件夹权限不足  
**解决**：
1. 以管理员身份运行命令行
2. 检查文件夹权限设置
3. 尝试手动复制单个文件
